Hermes Agent Skill

Hermes Agent

Skill介绍

在 Hermes Agent 的架构中，Skill（技能）可以理解为 Agent 的“外挂知识包”或“专项操作手册”。它是一套按需加载的文档和指令集合，采用了渐进式披露（Progressive Disclosure）模式。这意味着 Agent 不会一次性把所有知识塞进有限的上下文窗口（Token），而是在真正需要时才会读取具体的 Skill 内容。这种设计极大地节省了 Token 消耗，并且完美兼容 agentskills.io 开放标准。

Hermes Agent中所有的 Skill 默认都存放在 ~/.hermes/skills/目录下，该目录下每个skill都是一个独立的目录，包含一个SKILL.md 文件（提供Skill功能和对应执行指令给大语言模型），以及可选的脚本或资源。完整的Skill文件结构如下：

~/.hermes/skills/  
├── devops/                         # 类别目录
│   ├── deploy-k8s/
│   │   ├── SKILL.md               # 主要说明（必填）
│   │   ├── references/            # 附加文档
│   │   ├── templates/             # 输出格式
│   │   ├── scripts/               # 可从 skill 调用的帮助程序脚本
│   │   └── assets/                # 补充文件
│   └── vllm/
│       └── SKILL.md

以上文件解释如下：

  • SKILL.md

    必须指定的核心文件，该文件中包含技能相关的元数据和执行指令，采用“YAML元数据 + Markdown指令”的混合格式。

    ---
name: my-skill
description: Brief description of what this skill does
version: 1.0.0
platforms: [macos, linux, windows]     # 可选 — 仅限于特定操作系统平台
---

# Skill 标题

## 何时使用
Trigger conditions for this skill.

## 操作步骤
1. Step one
2. Step two

## 常见陷阱
- Known failure modes and fixes

## 验证方式
How to confirm it worked.

    • YAML元数据区（位于文件顶部—内）：用于定义Skill的基本属性，元数据区包含name（英文，Skill的唯一标识符，如 hello_world，名称必须为小写字母、数字和单连字符组合（如 git-release），且目录名需与此一致）、description（对Skill功能的简要描述，帮助AI理解何时调用此技能）。

    • Markdown指令区：用自然语言清晰描述AI应如何执行任务。该部分核心原则是导AI“做什么”和“用什么工具做”，而非教授AI基础知识，内容可以包括任务触发条件、分步操作流程、所需调用的工具（如 echo, bash）、输出结果的格式或标准。

  • 其他目录

    另外三个目录用于存放支持技能运行的资源，使Skill更强大、更独立。

    • scripts/: 存放可执行的Shell、Python等脚本，供Skill指令调用。
    • references/: 存放相关的规范文档、数据表等参考材料。
    • assets/: 存放模板文件、示例图片、配置文件等静态资源。

关于Skil使用，Hermes Agent中采用渐进式披露模式，该模式采用了类似计算机系统中“虚拟内存”的三级加载机制：

  • Level 0（只记目录）：系统启动时会扫描 ~/.hermes/skills/，但只读取每个技能的 名字、简述和 分类。大约只占 3k Token，相当于 AI 脑子里有了一张“技能目录索引卡”。
  • Level 1（查阅正文）：当你在聊天中输入 /github-pr-workflow或通过自然语言触发时，AI 才会去把该技能的详细操作指南（SKILL.md 全文）加载到上下文中。
  • Level 2（查阅附录）：如果技能附带了参考资料（如 API 文档、模板），AI 还可以进一步按需加载特定的参考文件。

Hermes 在安装时会将一个大型内置技能库复制到 ~/.hermes/skills/ 目录下，可以参考：https://hermes-agent.nousresearch.com/docs/zh-Hans/reference/skills-catalog ，也可以在Hermes Agent中对话询问已有的skill，也可以列出目前已有的内置技能。

自定义Skill并使用

如下定义一个Skill，功能是根据用户搜索关键字去网络中获取相关新闻，然后将结果写入到md文档中，该skill名称为“tech-news”，创建skill步骤如下：

  1. 创建SKILL文件

    在Ubuntu系统终端执行如下命令：

    # 创建目录
mkdir -p ~/.hermes/skills/news/tech-news
# 创建主文件
touch ~/.hermes/skills/news/tech-news/SKILL.md

  2. 编写SKILL内容

    打开 SKILL.md 写入如下内容：

    ---
name: tech-news
description: 搜索并总结过去24小时内关于指定关键词的全球科技新闻，并将总结的新闻写入到md文件中。
version: 1.0.0
---

# 全球科技新闻速报生成器

## When to Use
当用户执行 `/tech-news [关键词]` 或在对话中提到“帮我看看最近关于 [某主题] 的新闻”、“总结一下今天的科技头条”时触发。

## Procedure
1.  **解析意图**：提取用户输入中的关键词（例如：`大模型`, `汽车`, `机器人`）。如果没有关键词，默认搜索“人工智能 AI 行业动态”。
2.  **获取资讯**：
    *   使用web_search搜索该关键字，可以搜索百度、必应、谷歌等网站，最多搜索2个网站即可。
    *   **时间限定**：在搜索语法中加入 `最近24小时` ，确保时效性。
    *   **数量控制**：获取前5条最相关的链接。
3.  **深度阅读与总结**：
    *   对于搜索到的每一个链接，必须访问并阅读全文内容。
    *   提取每篇文章的：核心事件（What）、关键影响（Impact）、相关方（Who）。
4.  **合成简报**：
    *   将所有信息汇总成一份 Markdown 报告，存入/home/zs/Desktop目录下。
    *   严禁编造不存在的信息，必须标注来源链接。
    *   输出语言必须符合中文。

## Pitfalls
- **时效性问题**：如果搜索不到过去24小时的内容，请扩大搜索范围至过去一周，并明确告知用户“未找到过去24小时内的强相关新闻，以下是近期的热点”。
- **访问受限**：如果遇到付费墙（Paywall）导致无法阅读全文，请根据摘要（Snippet）进行总结，并标注“原文可能需要订阅”。

## Verification
检查是否每一条新闻都附带了 `[来源]` 链接，且内容是否涵盖了具体的数字、人名或产品名，而非空洞的形容词堆砌。

## Output Format Template
请严格按照以下格式输出：

> # 📰 科技新闻速报：[关键词]
> **生成时间**：[当前时间]
> **监测范围**：过去 24 小时
>
> ---
>
> ### 1. [新闻标题 1]
> - **核心摘要**：[用一句话说明发生了什么，包含具体数据或结论]
> - **深度解读**：[为什么这件事重要？对市场/技术有什么潜在影响？]
> - **来源**：[来源网站名称](URL)
>
> ### 2. [新闻标题 2]
> - **核心摘要**：[...]
> - **深度解读**：[...]
> - **来源**：[...]
>
> ---
> **💡 趋势洞察**：
> [综合上述新闻，给出一个关于该领域未来走向的简短预测或观察]

  3. 进入Hermes 并使用 skill

    进入hermes ，使用“/技能”可以调用到对应skill。

    使用中文告诉我你具备什么skill?


    /tech-news 中国AI发展

    查看对应目录中也有对应的md文件。

网络下载Skill并使用

Hermes Agent中还可以通过ClawHub搜索公开、免费的Skill。ClawHub是OpenClaw的官方公共技能中心，完全免费开放且每个skill都有版本历史，地址：https://clawhub.ai/skills 。如果想为Hermes Agent添加新功能，ClawHub是最简单的查找和安装技能的方式。此外，推荐一个Skills中国网站：https://hub.cocoloop.cn/

直接进入ClawHub官网搜索技能，找到对应技能名称再进行安装：

将下载好的SKILL技能包解压放入“~/.hermes/skills/<类别目录>/<skill名称>”目录下即可。

/china-weather 天津最近天气情况

这里导出微信公众号文章技能来演示如何在HermesAgent中配置使用外部的skill。该skill地址：https://clawhub.ai/8421bit/wechat-article-reader ，我们可以下载该SKILL 直接上传至“~/.hermes/skills/weixin/”目录下后并解压即可（weixin目录需要手动创建）。

进入到hermes agent中使用该技能：

/wechat-article-reader 下载这篇文章 https://mp.weixin.qq.com/s/xxx,把这篇公众号文章导出为 markdown 保存微信文章到本地
