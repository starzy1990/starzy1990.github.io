内置工具介绍

OpenClaw 有很多内置工具，这些工具是OpenClaw丰富功能的基石，可以通过 https://docs.openclaw.ai/tools 查看内置工具，这些内置工具介绍如下：

  • apply_patch Tool:允许一次性、原子性地对单个或多个文件进行复杂的更改。
  • Brave Search：OpenClaw 使用 Brave Search 作为 web_search 的默认提供商，可以进行网络搜索。注意：需要付费。
  • Perplexity Sonar ：OpenClaw 中 web_search工具的另一个搜索提供商（provider）选项。注意：需要付费。
  • Diffs:核心功能是将文本内容的更改（差异）可视化，用于清晰呈现“修改了什么”。
  • PDFTool：读取PDF文档，需要大模型原生支持PDF文件读取。
  • Exec Tool：执行工具，执行shell命令，支持前台和后台执行。
  • Exec Approvals：执行批准，用于控制Agent在真实主机上执行命令的安全护栏，只有用户批准都同意时，才允许执行命令。
  • LLM Task:结构化输出,强制模型输出纯 JSON 格式，运行过程中不会暴露任何工具调用。
  • Lobster :Lobster 是 OpenClaw 中一个用于运行类型化、可组合工作流管道的可选插件工具。其核心设计理念是将多步骤、需要人工审批的复杂任务，封装成一次确定性的操作，从而减少 AI 代理的来回调用和 Token 消耗。
  • Reaction:该功能为表情回复功能，允许 OpenClaw 代理在支持的聊天平台上，对特定消息执行添加或移除表情符号回复。

配置操作系统文件功能

OpenClaw安装后，默认对话中操作系统文件是禁止的，即不能读取、查看文件。可以通过如下命令来切换到完整工具集使用，放开文件读写（read/write）、命令执行（exec）、浏览器控制等能力。

在Ubuntu终端执行如下命令：

# 使用完整工具集
openclaw config set tools.profile full

# 设置执行主机为gateway，表示本机，如果使用docker部署需要设置为 sandbox
openclaw config set tools.exec.host "gateway"

#重启gateway
openclaw gateway restart

以上命令执行完成后，实际等同于在 /home/starzy/.openclaw/openclaw.json 文件中tools部分加入如下内容：

我有一系列工作需要做，请一次性完成如下内容：
1. 在桌面上创建 my\_dir目录，我的桌面地址/home/starzy/Desktop
2. 然后在该目录中创建"data.txt"文件 
3. 在该文件中写入"hello word" 
4. 并在最后将"data.txt"这个文件重命名为"hello.txt"

配置网络搜索功能

OpenClaw中内置工具支持的Brave Search和Perplexity Sonar两个网络搜索工具都需要付费，没有免费额度且需要绑定信用卡验证，国内使用不方便，我们可以通过配置让OpenClaw使用Tavily进行网络信息搜索。

Tavily是一款专为大型语言模型（LLM）和AI智能体（Agent）设计的实时搜索引擎API，它通过简单的API调用为AI应用提供精准、高效的信息支持，自动提取关键信息，去除广告和SEO优化内容，优先展示权威来源。

Tavily官网地址：https://app.tavily.com/home ，用户注册后，免费版每月提供1000次API调用，适合个人开发和小规模使用。

OpenClaw使用Tavily搜索功能需要配置 openclaw-tavily 插件，可以参考：https://github.com/framix-team/openclaw-tavily ，该插件具备多个工具，如下：

  • tavily_search：核心搜索功能。
  • tavily_extract：从 URL 中提取干净的标记下载/文本内容。
  • tavily_crawl：系统化爬取网站内容。
  • tavily_map：发现并列出网站上的所有 URL。
  • tavily_research：通过全面的报告进行深入研究任务。

OpenClaw使用配置“openclaw-trvily”插件具体步骤如下：

1) 获取Tavily apikey

登录 https://app.tavily.com/home ，获取apikey：

2) 从源代码安装“openclaw-tavily”插件

#在Ubuntun终端执行如下命令
git clone https://github.com/framix-team/openclaw-tavily.git ~/.openclaw/extensions/openclaw-tavily
cd ~/.openclaw/extensions/openclaw-tavily
npm install --omit=dev

3) OpenClaw中配置tavily apikey

打开“/home/.openclaw/openclaw.json”文件，在“plugins”模块，配置“entries”，增加如下内容并保存。

"openclaw-tavily": {
        "enabled": true,
        "config": {
          "apiKey": "tvly-dev-m...."
        }
      },

在plugins中配置allow,配置内容加入“openclaw-tavily”:

"plugins": {
    "allow":[
      "openclaw-tavily"
    ]
  },

4) 重启OpenClaw gateway

openclaw gateway restart

5) OpenClaw客户端进行网络搜索测试

配置 Firecrawl 爬取网页功能

firecrawl 是 OpenClaw 中用于 web_fetch 工具的备用内容提取服务，专门处理 JavaScript 密集型网站或被普通 HTTP 抓取屏蔽的页面。该工具可以绕过反爬虫机制、智能缓存爬取结果、智能提取页面主要内容并去除广告。

在 OpenClaw 中使用 Firecrawl 需要首先获取firecrawl apikey，登录 https://www.firecrawl.dev/ 获取 firecrawl 的 apikey（注册账号后，默认免费500 credits，即抓取500个网页）:

然后在Ubuntu中配置 /home/starzy/.openclaw/openclaw.json 文件，在tools部分添加如下内容：

{
  "tools": {
    "web": {
      "fetch": {
        "firecrawl": {
          "apiKey": "fc....",
          "baseUrl": "https://api.firecrawl.dev",
          "onlyMainContent": true,
          "maxAgeMs": 172800000,
          "timeoutSeconds": 60
        }
      }
    }
  }
}

当存在 apikey 时，firecrawl.enabled 默认为true；MaxAgeMs控制缓存结果可以保存多久（毫秒），默认2天。

以上配置完成后，执行如下命令重启geteway生效:

openclaw gateway restart

配置OpenClaw操作浏览器

OpenClaw 能操作所有主流的 Chromium 浏览器（Chrome、Brave、Edge、Chromium），不支持 Firefox、Safari 等非 Chromium 内核的浏览器。

本机模式中，OpenClaw 会按 Chrome → Brave → Edge → Chromium → Chrome Canary 的顺序自动检测并选用第一个可用的 Chromium 浏览器。

按照如下步骤安装Chrome浏览器并通过与OpenClaw对话操作浏览器：

1) Ubuntu安装Chrome浏览器

#使用wget下载浏览器
cd /home/starzy
wget https://dl.google.com/linux/direct/google-chrome-stable_current_amd64.deb

#安装Google Chrome浏览器
sudo apt install ./google-chrome-stable_current_amd64.deb

2) 与OpenClaw对话通过浏览器搜索内容
